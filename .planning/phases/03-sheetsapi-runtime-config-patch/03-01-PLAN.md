<objective>
Patch src/lib/sheets-api.ts to resolve the Google Apps Script URL at call time from SettingsService, falling back to the VITE_GAS_URL environment variable when no runtime config is stored.

Purpose: Currently the GAS URL is captured once at module load via `const GAS_URL = import.meta.env.VITE_GAS_URL`. This means any URL written to SettingsService after module import is invisible to API calls. The patch makes user-configured URLs take effect immediately without a page reload.

Output: A patched src/lib/sheets-api.ts with per-call URL resolution and zero public API surface changes.
</objective>
