4. **Live macro calculation** (per D-14) — derive totals on every render (NOT stored in state):
   ```typescript
   function calcTotals(ings: { foodId: string; grams: number }[], foodMap: Map<string, FoodItem>) {
     return ings.reduce((acc, ing) => {
       const food = foodMap.get(ing.foodId);
       if (!food) return acc;
       const ratio = ing.grams / 100;
       return {
         cal: acc.cal + food.cal * ratio,
         protein: acc.protein + food.protein * ratio,
         fat: acc.fat + food.fat * ratio,
         carbs: acc.carbs + food.carbs * ratio,
         sodium: acc.sodium + food.sodium * ratio,
       };
     }, { cal: 0, protein: 0, fat: 0, carbs: 0, sodium: 0 });
   }
   ```

   Build a `Map<string, FoodItem>` from the `foods` prop for O(1) lookup:
   ```typescript
   const foodMap = useMemo(() => new Map(foods.map(f => [f.id, f])), [foods]);
   const totals = calcTotals(ingredients, foodMap);
   ```

5. **Totals display** — show at top of ingredient section in a summary card:
   - `熱量: {Math.round(totals.cal * 10) / 10} kcal`

**C. Open Food Facts search** (per D-17, D-18, D-19, D-20, D-21):

1. **OffSearchPanel sub-component** — shown when user clicks "搜尋 Open Food Facts" button in the compose form.

2. **Search input** with debounced fetch:
   ```typescript
   const [offQuery, setOffQuery] = useState("");
   const [offResults, setOffResults] = useState<OffProduct[]>([]);
   const [offLoading, setOffLoading] = useState(false);

   useEffect(() => {
     if (!offQuery.trim()) { setOffResults([]); return; }
     const timer = setTimeout(async () => {
       setOffLoading(true);
       try {
         const url = `https://world.openfoodfacts.org/cgi/search.pl?search_terms=${encodeURIComponent(offQuery)}&json=true&page_size=10&fields=product_name,nutriments,serving_size,image_front_small_url`;
         const res = await fetch(url);
         const data = await res.json();
         setOffResults(data.products ?? []);
       } catch {
         setOffResults([]);
       } finally {
         setOffLoading(false);
       }
     }, 300);
     return () => clearTimeout(timer);
   }, [offQuery]);
   ```

3. **Result cards** (per D-19) — each shows:
   - Product name (text-sm, text-slate-100)
   - Calories per 100g (text-xs, text-slate-400)
   - Thumbnail image if `image_front_small_url` exists (24x24 rounded)
   - Tap handler: creates a new FoodItem from OFF data, saves it via `onSave` (which calls `ItemService.saveFood`), and adds it as an ingredient row

4. **OFF to FoodItem mapper** (per D-20):
   ```typescript
   function offProductToFood(p: OffProduct): FoodItem {
     const n = p.nutriments;
     return {
       id: `food_${Date.now()}`,
       type: "food",
       name: p.product_name ?? "未知食品",
       serving: "100g",
       cal: Math.round(n["energy-kcal_100g"] ?? 0),
       protein: Math.round((n.proteins_100g ?? 0) * 10) / 10,
       fat: Math.round((n.fat_100g ?? 0) * 10) / 10,

       sodium: Math.round((n.sodium_100g ?? 0) * 1000),  // g to mg
       source: "Open Food Facts",
     };
   }
   ```

   d. Add as ingredient row: push `{ foodId: newFood.id, grams: 100 }` to ingredients state
   e. Close the OFF search panel

**D. Save handler for composed food** (per D-15):

```typescript
function handleComposeSave() {
  if (!name.trim()) { /* show error */ return; }
  const validIngredients = ingredients.filter(i => i.foodId && i.grams > 0);
  if (validIngredients.length === 0) { /* show error "請至少新增一個食材" */ return; }

  const t = calcTotals(validIngredients, foodMap);
  const food: FoodItem = {
    id: `food_${Date.now()}`,
    type: "food",
    name: name.trim(),
    serving: serving.trim() || `${validIngredients.length} 種食材`,
    cal: Math.round(t.cal * 10) / 10,
    protein: Math.round(t.protein * 10) / 10,
    fat: Math.round(t.fat * 10) / 10,
    carbs: Math.round(t.carbs * 10) / 10,
    sodium: Math.round(t.sodium),
    source: "自行組合",
    ingredients: validIngredients,
  };
  onSave(food);
}
```
