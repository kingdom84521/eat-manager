**Pure functions (defined above component):**

1. `calcRemainingUnits(suppId: string, inv: InventoryEntry[], consumption: ConsumptionEvent[]): number` — same formula as updated SupplementManager: `Math.max(0, purchased - consumed)`.

2. `hasConflict(a: SupplementItem, b: SupplementItem): boolean` — bidirectional check: `a.interactions.includes(b.id) || b.interactions.includes(a.id)` (per D-06, D-07).

3. `slotHasConflict(candidate: SupplementItem, occupants: SupplementItem[]): boolean` — returns `occupants.some(occ => hasConflict(candidate, occ))`.

4. `hasSynergy(a: SupplementItem, b: SupplementItem): boolean` — bidirectional: `a.synergies.includes(b.id) || b.synergies.includes(a.id)` (per D-09).

5. `generateRoutine(supplements: SupplementItem[], inventory: InventoryEntry[], consumption: ConsumptionEvent[])` — returns `{ slots: Map<SupplementTiming, { item: SupplementItem; movedFrom?: SupplementTiming; conflictWith?: string }[]>; unscheduled: { item: SupplementItem; conflicts: string[] }[] }`.

   Algorithm (per D-04, D-06, D-07, D-08, research Pattern 1):
   - Step 1: Filter to `isActive === true` AND `calcRemainingUnits(s.id, inv, consumption) > 0` (per D-17)
   - Step 2: Sort by `a.id.localeCompare(b.id)` for determinism (per D-07)
   - Step 3: Initialize `slotMap: Map<SupplementTiming, ...[]>` with empty arrays for each timing
   - Step 4: For each supplement in sorted order:
     a. Try each timing in `supp.timing` (preferred slots). If `timing` is empty, default to `["with_meal"]` (research Open Question 3).
     b. For each preferred timing: if `!slotHasConflict(supp, occupants)`, assign here with no warning, `break`.
     c. If no preferred slot worked: try ALL `TIMING_ORDER` slots. If one has no conflict, assign there with `movedFrom = supp.timing[0]` and `conflictWith = name of the conflicting supplement in original slot`. Show warning badge (per D-06).
     d. If still no slot: add to `unscheduled` array with list of conflicting supplement names (per D-08).
   - Step 5: Return `{ slots, unscheduled }`

```typescript
useEffect(() => {
  Promise.all([
    ItemService.getSupplements(),
    ItemService.getInventory(),
    ItemService.getConsumption(),
  ]).then(([supps, inv, cons]) => {
    setSupplements(supps);
    setInventory(inv);
    setConsumption(cons);
    // Restore daily log
    const today = todayStr();
    const log = ItemService.getDailyLog(today);
    if (log) {
      const states = new Map<string, TakenState>();
      log.takenIds.forEach((id) => states.set(id, "taken"));
      (log.skippedIds ?? []).forEach((id) => states.set(id, "skipped"));
      setTakenStates(states);
    }
    setLoading(false);
  });
}, []);
```

Toggle handler (per D-10, D-11, D-12, D-13, Pitfall 1):
```typescript
const handleToggle = useCallback((suppId: string) => {
  setTakenStates((prev) => {
    const next = new Map(prev);
    const current = prev.get(suppId) ?? "untouched";
    let newState: TakenState;
    if (current === "untouched") {
      newState = "taken";
      // Deduct inventory — ONLY on untouched -> taken transition (Pitfall 1)
      const supp = supplements.find((s) => s.id === suppId);
      if (supp) {
        ItemService.logConsumption({
          supplementId: suppId,
          date: todayStr(),
          units: supp.unitsPerDose,
        });
        // Optimistic update of local consumption state
        setConsumption((c) => [...c, { supplementId: suppId, date: todayStr(), units: supp.unitsPerDose }]);
      }
    } else if (current === "taken") {
      newState = "skipped";
    } else {
      newState = "untouched";
    }
    if (newState === "untouched") {
      next.delete(suppId);
    } else {
      next.set(suppId, newState);
    }
    // Persist daily log (per D-14)
    const takenIds = [...next.entries()].filter(([, s]) => s === "taken").map(([id]) => id);
    const skippedIds = [...next.entries()].filter(([, s]) => s === "skipped").map(([id]) => id);
    ItemService.saveDailyLog({ date: todayStr(), takenIds, skippedIds });
    return next;
  });
}, [supplements]);
```
