# Quick Task 260330-88s: Replace Age Input with Birthday Date Picker — Summary

**One-liner:** Inline calendar birthday picker replacing age number input; schema migrated from v1 (ageYears) to v2 (birthday ISO string) with approximate Jan-1 conversion for existing users.

## What Was Built

### UserProfile Schema Change (Task 1)
- `UserProfile.ageYears: number` replaced with `birthday: string` (ISO YYYY-MM-DD)
- `computeAgeFromBirthday(birthday: string): number` added and exported from `settings-service.ts` — computes full years elapsed, accounts for whether birthday has occurred this year, clamped 10-120
- `defaultSettings()` bumped to `settings_version: 2`
- `migrate()` restructured from switch/fallthrough (blocked by `noFallthroughCasesInSwitch`) to sequential if-blocks — v1 converts `ageYears` to `birthday` as `YYYY-01-01`, v2 is current schema
- `getComputedTargets()` calls `computeAgeFromBirthday(profile.birthday)` before passing age to `calculateBMRResult`
- `bmr.ts` functions unchanged — still accept `ageYears: number`

### BirthdayPicker Component (Task 2)
- Pure React/Tailwind inline calendar — no external library
- Props: `value: string` (ISO date or ""), `onChange: (date: string) => void`
- Text input displays selected date as "YYYY / MM / DD" or placeholder "選擇生日"
- Clicking input toggles an inline calendar block (pushes content down, not a dropdown)
- Calendar features:
  - Header: month/year display with left/right navigation arrows
  - Year selector: clicking the header toggles a scrollable year list (range: currentYear-120 to currentYear-10), auto-scrolls to selected year
  - Day-of-week headers: 日 一 二 三 四 五 六
  - Day grid: 6x7 cells, prev/next month days dimmed
  - Selected day: `bg-blue-600 text-white` highlighted
  - Today: `ring-1 ring-blue-400` ring indicator
  - Clicking a day sets value and collapses calendar
  - Click-outside handler collapses calendar (useRef + useEffect)
- Default view: birthday month if set, otherwise January of (currentYear - 30)
- All text in Traditional Chinese

### Settings.tsx Updates
- `ProfileFormState`: `ageYears` -> `birthday`
- `ProfileErrors`: `ageYears?` -> `birthday?`
- `validateProfile`: birthday empty or computed age outside 10-120 triggers "請選擇有效的生日（年齡須介於 10–120 歲）"
- `isProfileComplete`: checks `form.birthday !== ""`
- `computeTdee`: uses `computeAgeFromBirthday(form.birthday)`
- `handleProfileChange`: saves `{ birthday: next.birthday, ... }` to SettingsService
- Initial state loads `birthday` from `savedProfile.birthday`
- JSX: age number input replaced with `<BirthdayPicker>`, label shows computed age "（N 歲）"
