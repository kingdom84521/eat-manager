# Quick Task 260406-h36: Fix OFF CORS

## Problem
Open Food Facts `cgi/search.pl` endpoint doesn't return `Access-Control-Allow-Origin` headers, causing CORS errors when called from GitHub Pages (`kingdom84521.github.io`).

## Solution
Proxy OFF searches through the existing GAS Web App:
1. Added `proxyOff` action to `doGet` in `scripts/gas-api.js` — uses `UrlFetchApp.fetch()` to call OFF server-side (no CORS)
2. Updated `src/pages/FoodManager.tsx` to route OFF queries through GAS proxy URL instead of direct fetch
3. Bumped `API_VERSION` to 3

## Files Changed
- `scripts/gas-api.js` — new `proxyOff` case, API_VERSION 2→3
- `src/pages/FoodManager.tsx` — import SettingsService, use GAS proxy URL for OFF search

## Deploy Note
User must redeploy GAS with updated `gas-api.js` (new version) for the proxy to work.
